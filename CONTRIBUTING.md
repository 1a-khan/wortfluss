# Contributing to Wortfluss

Thank you for your interest! Wortfluss is created and maintained by
[Ammad Khan / MIAK IT](https://miak-it.de).

- **Found a bug?** Open an issue with the *Bug report* form.
- **Have an idea?** Open an issue with the *Feature request* form.
- **Want to change code?** Fork the repository, make your change on a branch, and open a pull
  request. Every change is reviewed by the maintainer before it is merged; nobody else can
  change the main branch directly. CI (Linux and Windows build and tests) must pass.

Please never include API keys, `secrets.env`, recordings or transcripts of other people in
issues or pull requests.

By submitting a contribution you agree that it is licensed under the
[Apache License 2.0](LICENSE), like the rest of Wortfluss (section 5 of the license).
